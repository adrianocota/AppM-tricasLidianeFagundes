# Métricas · Lidiane Fagundes Advogada

App simples de controle de retorno do tráfego pago.

## O que ele faz

- Lançamento mensal de investimento, cliques e conversas (aceita meses retroativos)
- Cadastro de contratos fechados com valor e forma de pagamento
- Faturamento calculado pela soma dos contratos do mês
- Retorno sobre investimento, custo por conversa, custo por cliente e ticket médio
- Evolução dos últimos seis meses e previsão de recebimento
- Cópia de segurança dos dados em arquivo

## Como usar

Abra o index.html no navegador do celular e adicione à tela inicial.

Os lançamentos ficam gravados no próprio aparelho. Nenhum dado é enviado para servidor.
Use a aba Cópia periodicamente para guardar um backup.

## Arquivos

- index.html — o app inteiro
- manifest.json — permite instalar como aplicativo
- icone.png — ícone da tela inicial
